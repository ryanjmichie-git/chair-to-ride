# Checkpoint spec template

## Goal
_One sentence: what this checkpoint proves true._

## Files
_Files created or edited, one per line._

## Out of scope
_What this checkpoint explicitly does not build yet._

## Definition of done
_Checkable conditions with numbers, not adjectives._

## Verification command
_The exact command(s) a reviewer runs to confirm Definition of done._

## PR checklist
- [ ] C1 — test output pasted
- [ ] C5 — reviewer findings attached and addressed, or waived with reason
- [ ] C8 — a lesson or a hook added if a misunderstanding caused a bug
- [ ] K2 — diff ≤ 400 changed lines in `src/`
